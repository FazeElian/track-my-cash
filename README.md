# 📄 Description
**Track My Cash** is a personal finance web app that helps you organize your income, expenses, and financial goals in one place. With an intuitive interface and powerful insights, it lets you track your financial habits, visualize your progress, and make smarter money decisions. Designed for simplicity and clarity, it’s the perfect tool to take control of your personal finances.

<br>

# 🚀 Main Features

- ✨ Dashboard with quick statistics and a monthly summary.
  
- 🧾 Recording and viewing **movements** (income and expenses).
- 🎯 Management of **financial goals** (objectives).
- 📊 Charts and analysis of income vs. expenses.
- 🔔 Progress and inactivity notifications.
- 📅 Filtering transactions & goals by type and status.
- 🔐 User authentication.
- 💡 User-friendly and responsive interface.

# ⛏ Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/FazeElian/thesis_pj-easy_finance.git
   ```

<br>

2. Install dependencies (on client & server side):
   ```bash
   npm install
   ```


3. Configure environmental variables
   
   Use the **.env.example** file on 📁client and 📁server side folders
   
<br>

3. Start Vite server (client)
   ```bash
   npm run dev
   ```

<br>

4. Start Express server (server)
   ```bash
   npm run dev
   ```
   If you want to use postman:
   ```bash
   npm run dev:api
   ```
